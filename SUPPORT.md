# Support

## Usage questions

Use [GitHub Discussions](https://github.com/ayhammouda/gsc-seo-mcp/discussions)
for setup help, integration questions, and ideas that are not yet actionable
bug reports.

## Bugs and feature requests

Use the repository's
[issue templates](https://github.com/ayhammouda/gsc-seo-mcp/issues/new/choose)
for reproducible bugs, feature proposals, and documentation improvements.
Search existing issues first and do not include credentials or private Search
Console data.

## Security vulnerabilities

Do not report vulnerabilities in a public issue or discussion. Follow the
[security policy](SECURITY.md) and use
[GitHub private vulnerability reporting](https://github.com/ayhammouda/gsc-seo-mcp/security/advisories/new).

## Release status

The project is source-only while its release freeze is active. Support does not
include the unrelated npm package that currently uses the unscoped
`gsc-seo-mcp` name.
